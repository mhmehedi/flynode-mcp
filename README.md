# FlyNode for Claude and the command line

Open-source client for [FlyNode](https://flynode.io). It holds no secrets and does nothing without an API token from a FlyNode account.

- `mcp/` - `@flynode/mcp`: MCP server (Claude Code, Claude Desktop, any MCP client) and the `flynode` CLI.
- `claude-plugin/` - Claude Code plugin: the MCP server, a `/flynode:deploy` command and a deploy skill.

Docs: https://flynode.io/docs (search "Deploy with Claude"). License: MIT.
